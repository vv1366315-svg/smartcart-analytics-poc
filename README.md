# SmartCart Analytics POC
**E-commerce user behaviour tracking and conversion analysis using Google Tag Manager (GTM), Google Analytics 4 (GA4), Python and SQL.**

> This is a learning/demo project. The included CSV contains **synthetic sample data**, not real customers or live GA4 exports. Replace it with appropriately exported data when available.

## What this project demonstrates
- A small static storefront that pushes ecommerce interactions to the GTM `dataLayer`.
- A GTM-to-GA4 event tracking plan for `view_item`, `add_to_cart`, `view_cart`, `begin_checkout` and `purchase`.
- Python/Pandas data checks, funnel metrics and a chart.
- SQLite tables and SQL queries for product, funnel and traffic-source analysis.
- A Streamlit dashboard for exploring the sample dataset.

## 1. Run the website
1. Open this folder in VS Code.
2. Open `website/index.html` in a browser using the VS Code Live Server extension, **or** run a local server:
   ```powershell
   cd website
   py -m http.server 8000
   ```
3. Visit `http://localhost:8000`.

The site uses a simulated cart and checkout. It does not take payments or collect payment details.

## 2. Connect GTM and GA4
Follow `docs/gtm-ga4-setup.md`. Replace `GTM-XXXXXXX` in `website/index.html` with your GTM container ID after creating a container. Configure a Google tag and event tags in GTM. The website's data layer events will not reach GA4 until those tags are configured and published (or tested in Preview).

## 3. Run Python analysis
From the project root in the VS Code terminal:
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python python/analyze.py
```
If PowerShell blocks activation, you can skip activation and run:
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe python/analyze.py
```
The script writes `outputs/event_analysis.png` and `outputs/smartcart.db`.

## 4. Run the dashboard (optional)
```powershell
streamlit run python/dashboard.py
```
The dashboard uses the synthetic CSV by default.

## 5. SQL
Open `sql/schema.sql` and `sql/queries.sql` in VS Code or use the SQLite database generated by `python/analyze.py`.

## 6. GitHub
In VS Code, open **Source Control** (Ctrl+Shift+G), choose **Initialize Repository**, stage the project files, commit, then select **Publish to GitHub**. Alternatively:
```powershell
git init
git add .
git commit -m "Build SmartCart analytics POC"
```
Then create an empty repository on GitHub and follow GitHub's instructions to add a remote and push. Do not commit credentials, tokens, or private analytics exports.

## Important implementation notes
- GTM manages tags; it does not automatically track every interaction merely by being installed.
- GA4 event tags must be configured in GTM to send the `dataLayer` events to GA4.
- Debug using GTM Preview / Tag Assistant and GA4 DebugView.
- Synthetic-data results must be labelled as illustrative, not as real business findings.
- For a real deployment, review consent requirements, privacy disclosures, session attribution and duplicate-event handling.
